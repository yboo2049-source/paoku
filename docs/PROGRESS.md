# 项目进展与重构日志 (Progress & Refactoring Log)

本文档用于记录核心机制的重大变更与功能落地，作为 Agent 协作的状态同步源。

## 最新进展 (Latest Updates)

### 3D 视觉与底层重构 (Visual & Physics Overhaul) - 已完成
*   **深渊坠落机制废弃**：根据用户需求，完全去除了地图生成中的悬空断层 (Gap_Jumps) 以及对应的坠崖判定（`player.z < -20`）。游戏世界统一为无尽平地。
*   **全景 3D 轨道引入**：使用 `THREE.Group` 构建了带有枕木、铁轨和视差边缘墙体的前进跑道，移除了原有的单调贴图网格，大幅提升深度感。
*   **障碍物 3D 化与碰撞修正**：
    *   **低矮障碍 (`LOW_OBSTACLE`)**：重建为带支柱的 3D 红色跨栏，物理碰撞域设定为贴地，强制要求玩家**跳跃**通过。
    *   **高空门架 (`HIGH_OBSTACLE`)**：重建为蓝色的 3D 广告牌结构。修复了生成系统中高度轴 (`z`) 未被正确赋值的严重 Bug。现在的物理碰撞域严格限制在半空，下方完全镂空，强制要求玩家**翻滚**通过。
*   **实体清理逻辑修复**：修复了长物体（如火车）在玩家未跑完其后半截时即被引擎提前清理（剔除）的 Bug。清理阈值已严格绑定至物体的尾端绝对坐标 (`entity.y + length / 2`)。
*   **PBR 材质升级**：所有的环境道具、金币（改用真实的纯金圆柱体附带旋转动画）、火车全部升级为带金属度/粗糙度的 `MeshStandardMaterial`，并启用了全局硬阴影投射。

## 历史遗留问题修复
*   修复了 Safari/部分 Chrome 核心下 Blob URL 解析 SVG 失败导致人物变“隐形人”的问题（已统一转为 Base64 内联方案）。
*   修复了 Resize 导致 3D 画布被 CSS 容器暴力裁切而引起的“视觉坐标偏移”、“右侧金币形变”等问题，`renderer.setSize` 现已完美贴合容器实际边界。
