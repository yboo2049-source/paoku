## 2. 造型、坐标与绑定候选

沿用原创运动服、清晰鞋型与背包剪影、暖色主体和冷色环境。珊瑚/深色衣裤等具体色号沿 PAO-7 候选；不擅自替换现有原创造型。参考高1.8m、约4.5头身、肩宽约0.55m，最终由同屏样板审查，不用A-pose张臂宽冒充肩宽或碰撞宽。

- 交付空间：m，+X右、+Y上、+Z角色面向前；脚底中心为角色局部(0,0,0)。静止绑定姿势双足鞋底最低点Y=0。DCC作者轴、单位、导出器和Babylon导入手性转换逐一登记，只在表现边界归一化一次。
- 1.8/0.9791≈1.838423 是按现有场景高的**候选等比标定**；不是生产缩放批准，不做非等比拉伸。若作者重置绑定姿势或几何，重新测完整节点/蒙皮后高度，不复用旧系数。
- 作者工具内采用对称A-pose、足尖前向、膝肘明确弯曲平面；记录肩/髋/膝/踝/鞋底基准。导出根TRS为平移0、旋转单位、缩放1，无负缩放；不能在有动画后随意Apply Transform破坏bind matrices。
- 导出单一命名骨架 `runner_rig_v1`；DCC控制器/IK约束烘焙到变形骨，不把控制器导出。逆绑定矩阵与rest pose一起验证。每顶点最多4个归一化权重，无未绑定顶点/NaN；LOD0/1共享骨架、关节索引语义与动作库。

候选基础树（23具名节点；挂点另外登记，导出总关节数仍≤48）：

```text
root_motionless
  pelvis
    spine_01
      spine_02
        neck -> head
        clavicle_l -> upperarm_l -> forearm_l -> hand_l
        clavicle_r -> upperarm_r -> forearm_r -> hand_r
        backpack
    thigh_l -> calf_l -> foot_l -> toe_l
    thigh_r -> calf_r -> foot_r -> toe_r
```

上图缩进/箭头表示父子；正式清单仍须写每个parent。root_motionless固定在脚底基准；pelvis可有局部重心运动。手指、面部、裙摆骨本批不加，确需增加先占≤48总额并说明。backpack为包体变形/刚性附属节点，是否计skin joint按导出清单明确；23为上图具名节点总数，不是现有资产已拥有的骨数。

蒙皮前提：原作者确认34段中哪些是衣物/皮肤/包、是否存在融合手指/腋下/裆部/膝弯、可否修改拓扑和UV。用肩抬90°、肘/膝弯120°、髋屈90°及滑铲极限姿势检查。需要补拓扑/重烘焙时先交返工清单，不能在本轮直接重建。衣物与身体交界权重连续，包带不穿肩；减面不得删除膝肘关节环。

## 3. 动作采样、循环和表现标记

统一30fps骨骼采样。帧从0起；`[0,N)`指0到N-1这N个播放采样，时长N/30秒。GLB须另有t=N/30的插值边界键（循环对应首姿态及连续切线，非循环对应终姿态），使导入器识别真实时长；不能只导到(N-1)/30造成短一帧。边界键不是多播放一帧，循环区间仍为[0,N/30)，不重复停留终点。此处细化PAO-7半开区间的导出语义，须用真实导入验收。所有clip的root平移/旋转保持绑定值、scale=1，**XYZ均无根位移**；跳高、前进、切道、支撑高度和滑板高度由模拟/表现接线拥有，骨架只做局部姿态。

下表是制作节奏与表现事件候选；不能改变模拟动作时长/可输入窗口。非循环到末帧只提供姿态，阶段不许由clip结束反推。`hit_frame=N/A`、`invincible_from/to=N/A（无美术无敌）`、`move_delta=(0,0,0)`适用全部clip。

| clip / N / 秒 | 姿势与分段帧 | 循环 / 末帧 | 表现标记与常规可打断起点 |
| --- | --- | --- | --- |
| idle / 60 / 2.0 | 0–59轻呼吸，双足固定 | 循环[0,60) | 无脚步；f0可转有效运动 |
| run / 24 / 0.8 | 0左足接触、6腾空、12右足接触、18腾空 | 循环[0,24) | foot_l=f0、foot_r=f12；f0可转任意有效阶段 |
| jump_start / 6 / 0.2 | 0–1压髋、2–3蹬伸、4–5收腿 | 非循环，混向jump_air | f2推蹬姿态标记；模拟已起跳立即播，f0可被更高优先事实打断 |
| jump_air / 12 / 0.4 | 0–11收腿/平衡，脚不钉地 | 循环[0,12) | 无落地标记；f0随模拟触地退出 |

共13 clip。滑铲三个clip是一套持续阶段，不强制按0.8秒串完；空中滑铲只改模拟认可的姿态，不把airborne改成supported。hoverboard是地面板上基础姿态候选，跳/滑/受击时由当前模拟阶段取上表动作，板作为附件跟随；不新增滑板攻击、飞行、无敌或物理高度。若基础动作与板无法共用，应作为新增board变体另审数量/成本。

## 4. 打断、混合与生命周期交接

优先顺序：退出/重开（清空）→终局fail→模拟空中/滑铲/落地阶段→非致命hit反馈→run/idle/hoverboard基础态；换道仅为受限上身加性层，可被以上阶段抑制。运行中verticalPhase和stance是正交事实，空中+滑铲同时存在时优先低姿态空中表现，不能等待动画完成再接受模拟结果。受击不保证玩法存在可恢复伤害；只在确有非致命事实时播，不能把所有碰撞都转成hit再延迟fail。

候选混合2–3帧（约0.067–0.1s），仅姿态插值；快速终局允许直接切换以避免延迟。lane加性仅spine/肩/头掩码，不改root/腿；作者源须提供以同rest pose为参考的增量或明确标为absolute再由PAO-18转换，不能两种口径混用。第二次切道从当前层权重重定向，不累加倾斜到失控。

run脚步标记仅在supported且非滑铲、且当前局有效时可消费；高低速时由PAO-18以候选0.75–1.5播放倍率试验与脚部滑移一起评审，不让脚步改变速度或模拟。PLAYER_LANDED/SUPPORT_CHANGED等按PAO-9事实语义映射，但不声称本稿已逐项核对M1实际导出字段；PAO-18接线前须对固定实现版本作最小适配审查。丢事件从快照恢复持续态，不能补播旧声效。

暂停冻结局内clip相位与表现标记，恢复不补跑墙钟；重开换runId清clip、层权重和标记游标；销毁停止播放器/解绑挂点。地面/坡/车顶以模拟脚底世界Y为准，只在局部pose调整接触观感，禁止反写支撑/碰撞。动作不能拥有无敌、拾取、伤害、结算或输入合法性。

## 6. 包体、预算与导出候选

继承PAO-7候选：runner LOD0≤12,000三角面、LOD1≤6,000；材质≤2，优先同材质合并成少量skinned primitive；总关节≤48，每顶点权重≤4。现有26,268面和34 primitive未达到该生产提案。是否可减面且保持原造型须原作者检查，不在准备阶段修改。Q0仍保留角色LOD0的可读轮廓分配，不用隐藏玩家降成本。

runner单套baseColor/normal/ORM预算：Q2每张1024，Q1/Q0每张512；无必要通道用常量。按RGBA8完整mip计，单角色三张分别16/4/4MiB；runner+chaser两套32/8/8MiB，**不是每个角色32MiB**。当前runner两张4K保守估算约170.6667MiB，不是压缩传输大小/实测GPU驻留；不可全量首屏加载。全场128/64/32MiB门禁属于PAO-8候选，不能由单角色局部预算宣称满足。

baseColor为sRGB，normal/ORM线性，ORM=AO/roughness/metallic；normal使用OpenGL Y+并附切线生成方式，导入凸凹复核。1024图集候选8px扩边、低档mip串色复核；LOD和clip复用贴图，不每clip嵌一套。KTX2/压缩是否采用待PAO-17加载器验证，本批不承诺未验证扩展。
