## 2. 风格锚点

明亮日间城市轨道，清晰而略夸张的圆角几何，温暖人物对比冷色环境，柔和单向阴影，克制金属反光。角色穿原创运动服，以大色块、轻便背包和明显鞋型形成剪影；完整列车保留车头、窗、门、底盘和车顶层次。检修坡道是能看懂坡脚到坡顶的连续斜面。近景服务路线判断，中景表现站台和街区，远景降对比。HUD 为浅色实体卡片、深色数字和少量语义色，与画布分层。禁止复制现有游戏人物、标识或在世艺术家的个人风格；禁止霓虹铺满轨道、湿亮全场、用立方体换色冒充正式道具、靠透明光晕掩盖碰撞轮廓。

## 3. 六类色彩语义与禁忌

下表是候选 token，不因本次写入而成为最终生产色板。色彩必须同时配合形状、空间位置、纹理和文案；灰度查看仍须区分危险、奖励与可通行面。

| 语义族 | 候选主色 / 辅色 | 世界用途与形状 | HUD 对应 | 禁忌 |
|---|---|---|---|---|
| 主角 | 珊瑚 `#EF725B`；深色 `#243F4B` | 暖色上衣、深裤、明确头肩与鞋剪影 | 头像、角色选中边线 | 不铺满建筑；危险不能仅复用珊瑚轮廓；皮肤换色仍须与环境分离 |
| 可通行 | 薄荷 `#69BDA4`；奶白 `#F7F3E9` | 坡面/可站车顶局部箭头、连续边缘；大面维持哑光 | 路线说明、可操作确认标记 | 不把全部列车车身涂成通行提示；非通行装饰不画同型向前箭头；不等同无条件安全 |
| 危险 | 红 `#D94B4B`；深色 `#243F4B` | 封闭挡板、斜纹、明确横向阻断剪影 | 失败原因、风险提示配图标 | 不用奖励金作为唯一危险标记；不用闪烁承担唯一提示；不将可通行坡面画成整块危险红 |
| 奖励 | 金 `#E4AD3F`；奶白高光 | 圆形有厚度金币、凹印原创标记 | 金币图标与收益数字附近点缀 | 不画成连续“安全路面”；不与危险共用圆形悬浮外形；不靠过曝发光辨认 |
| 道具 | 紫 `#8C6BC4`；奶白图形 | 磁铁 U、倍分菱牌×2、成对鞋、长板四种剪影 | 同形图标＋中文名＋倒计时/进度 | 禁止四个相同立方体；紫不表示稀有度或危险；不得显示内部枚举字符串 |
| 环境 | 冷蓝 `#9DC3D4`；列车青绿 `#397C87`；奶白 | 建筑、天空、轨道街区；近中远降低细节与对比 | 浅底 `#F7F3E9`、正文 `#243F4B` | 背景不争用危险红/奖励金大面积高饱和块；列车青绿本身不代表可站立 |

建议屏幕大面积由环境和中性底承担，语义色只在主体与交互点集中。明度次序为深色文字/底盘 → 列车青绿 → 主角/危险/道具中间调 → 通行/环境 → 奶白高光；金币以形状和边缘分离，不追求最高亮度。不得仅凭色号推断最终可读性，必须在实际灯光、背景、灰度和缩略图下复核。

## 4. 比例、几何与构图

### 4.1 尺度提案与坐标交接

生产空间提案采用 1 单位 = 1 米、X 横向、Y 向上、Z 前进；角色前向 +Z、脚底中心为原点，静态模块原点置底面中心，坡道原点置坡脚中心。导出应用缩放为 1，模型不得带隐藏负缩放。Blender 等工具的作者坐标与导出坐标转换须随文件记录。Babylon.js 左右手与 glTF 导入转换、支撑面字段及尺度最终由 PAO-9 契约确认；不得在资产里额外旋转来“修好”重复转换。

| 对象 | 候选尺度 | 约束 / 验证 |
|---|---|---|
| 角色 | 高 1.8m，约 4.5 头身，肩宽约 0.55m | 轻夸张头手脚；不以美术轮廓自行修改碰撞；滑铲姿势清晰低于站立轮廓 |
| 三车道 | 暂沿用中心距 3m 的基线参考 | 美术不冻结新玩法尺寸；实际车道、实体宽度与安全间隙交 PAO-9 |
| 列车样板 | 宽 2.4m、高 3m、车厢长 18m | 车顶平面与可站区明确；车门、窗、轮、底盘齐备；可站区不堆假障碍 |
| 坡道样板 | 宽 2.4m、水平长 12m、升高 3m | 为 PAO-6 夹具对照尺寸，坡角约 14°，不是冻结的所有关卡尺寸 |
| 金币/道具 | 金币直径约 0.4m；道具外包络约 0.6m | 可视大小与拾取范围分离记录；细节缩小后不丢主要剪影 |

坡道顶面必须由与物理支撑相同的起止点生成，坡体不得高于可走面挡住躯干。视觉检查包含坡脚、坡中、坡顶、车顶、跳离和落地；必须叠加脚底/支撑面调试线，检查基准高度、左右边缘和连接缝。这里只定义交付约束，不引入新的 Surface 接口、碰撞公式或豁免阈值。连通不代表生成器所有随机组合可达。

静态与迎面列车共享完整车身家族，移动列车额外交付迎面方向标记、非闪烁危险前板与明确运动参照；配合运动、灯光和声音提示区分，不能只靠红灯或车身换色。薄荷通行箭头只放在关卡契约明确允许的连续支撑面，移动列车是否能站立由玩法契约决定；本稿不授予移动列车安全属性，车顶浅色本身不构成通行承诺。接近方向、高速和遮挡情况下的可辨识性须在实际引擎录像中验收。

### 4.2 镜头与 UI 保留区

建议桌面角色脚底落在画面横向中心附近、纵向 78%–88%，头部大致在 58%–72%；这是未来引擎样板的构图目标。1440×1000的SVG展示板包含注释和图例，其中人物为概念化剪影、不是4.5头身的尺寸图；说明性透视不作为镜头标定数值。图内列车只示静态车族，不能由浅色车顶推断移动列车可上。换道、上坡、车顶跳跃及追捕实体均不得长期出框，不能为保持人物屏幕高度而突然跳镜。角色到前方消失点的中央路线区域优先留空，边缘环境不压住转向判断。

HUD 候选使用 8px 间距基元；桌面外边距 24px，竖屏外边距至少 16 CSS px，再叠加设备 safe-area。主要按钮触控范围至少 44×44 CSS px；基本文字建议 16 CSS px、关键成绩 24–32 CSS px。分数/币数固定宽度数字，顶部两侧布置，暂停右上；道具条靠边不盖住人物；任务 Toast 限长，避开中央前视区。390×844 是参考 viewport，不等于手机真机验证；超长数值、200% 字号、横竖屏和安全区另由 PAO-19 实测。

菜单需留出可见人物预览和独立开始按钮；暂停、结算、商店统一卡片与按钮状态（常态/悬停/按下/禁用及键盘焦点），保留旧版音频偏好与资产所有权能力。速度单位在 PAO-9 确认前只写“速度”，不沿用未换算的 KM/H。小样 HUD 为静态虚构展示值，不代表实际得分或已实现状态。

## 5. 材质、贴图与灯光规格提案

| 材质族 | 金属度 / 粗糙度候选 | 要求 |
|---|---|---|
| 布料/鞋 | 0 / 0.75–0.9 | 大色块，细纹不成为屏幕噪声 |
| 车身涂漆/坡道涂层 | 0 / 0.5–0.7 | 不因底材是金属就把漆面设成镜面金属 |
| 裸露轨/底盘局部 | 1 / 0.4–0.65 | 高光沿结构走，不能发白吞掉边缘 |
| 水泥/建筑 | 0 / 0.8–0.95 | 中远景弱对比，避免写实噪声 |
| 窗与灯 | 暗色不透明窗优先；灯局部自发光 | 不追求透明层数；灯不照亮整条轨道，低档关闭 bloom 也可辨认 |

主光建议来自画面左上，偏暖日光、冷色柔和环境补光；阴影方向全资产一致。角色必须有足底接触阴影。曝光在样板中固定，比较坡道、车顶、隧道入口和高亮金币时不得靠逐图调曝光掩饰失衡。先在无 bloom、无全屏速度线状态验收轮廓，再添加少量效果；效果不可成为通行提示的唯一来源。真实曝光/灯强度数值依赖最终色彩管线，PAO-7 不伪造已测参数。

贴图统一命名 `tex_<assetId>_<channel>_<size>_v01.png`，作者源保留分层文件。baseColor/emissive 为 sRGB；normal、AO、roughness、metallic 及 ORM 为线性，ORM 固定 R=AO/G=roughness/B=metallic。法线交付 OpenGL Y+，另存切线生成方式；用引擎凸凹测试确认导入，不同时翻绿通道与翻切线。无贴图需求的材质直接交参数，不添加空白 4K 贴图。

候选密度为近景平铺件 256px/m、角色 512px/m，中远景按 LOD 降档；每件写实测 UV 密度及例外原因。UV 不意外重叠，对称复用明确登记；1024 图集至少 8px 扩边，并检查 mip 后串色。高模只用于烘焙，不导入游戏；交低模、必要法线/AO、材质和烘焙配置。透明物、遮挡代理和碰撞代理单独标记，禁止直接拿渲染网格充当碰撞体。

## 6. 同屏预算与制作批次

以下是可复核的制作上限提案，不是 PAO-6 性能实测，不是 PAO-8 已冻结预算，也不承诺任何硬件帧率。PAO-8 评估后可以下调；在确认前不得据此批量制作高成本资产。

| 类别 | 样板同屏上限 × LOD0 三角面 | 估算三角面 | 单件贴图/材质建议 |
|---|---|---:|---|
| 玩家与追捕角色 | 2 × 12,000 | 24,000 | 每个 1 套 1024 PBR；最多 2 材质 |
| 完整列车 | 3 × 6,000 | 18,000 | 车族共用 1 套 1024；每件最多 2 材质 |
| 坡道与高低障碍 | 8 × 800 | 6,400 | 共用 1 套 512；单件 1 材质 |
| 金币与四道具 | 50 × 400 | 20,000 | 共用 1 套 512；优先实例复用 |
| 轨道/站台近景模块 | 20 × 1,200 | 24,000 | 共用 2 套 1024，平铺/图集 |
| 中远景模块 | 20 × 1,000 | 20,000 | 共用 1 套 1024，优先实例复用 |
| 效果几何余量 | 总量 | 2,000 | 透明粒子另受覆盖率限制 |
| 合计 | 上述数量是预算夹具，不是关卡配置 | 114,400 | 暂留至 150,000 上限的 35,600 面余量 |

纹理估算采用 RGBA8 解压驻留并含完整 mip 链：1024 单张约 5.33MiB，512 单张约 1.33MiB。7 套 1024 三贴图 PBR（角色2、车族1、近景2、中远景1，另留1套）约 112MiB；2 套 512 三贴图约 8MiB；2 张 1024 RGBA UI/FX 图集约 10.67MiB；合计约 130.67MiB，候选纹理上限 160MiB。这个估算不含阴影、帧缓冲、环境立方体、顶点/索引或驱动开销，不当作总显存，也不把磁盘 PNG 大小当驻留量。压缩格式与传输预算交 PAO-8 实测。

LOD 候选 L0/L1/L2 = 100%/50%/20%；主角至少 L1，列车与建筑至少 L2；切换按屏幕占比确定，轮廓与通行边缘不跳变。近景轮廓不能靠贴图假造斜面。首批只做一个角色、一组动作、车头/车厢、一坡、高低栏、金币四道具、一个轨道街区和 HUD 样板；审过实机样板后才扩主题。draw call、透明覆盖率、加载体积、阴影档和目标机型由 PAO-8 统一确定，本稿不额外冻结冲突值。

## 7. 动作与特效交付提案

正式角色以一致骨架、原地骨骼动画驱动；统一 30fps 采样，所有 clip 记录采样区间与秒数。以下时长是美术节奏参考，不决定模拟时长、无敌帧或输入窗口。

| clip / 采样帧（从0开始，不含结束边界） | 循环与结束 | 关键约束 |
|---|---|---|
| idle / [0,60)，2s | 循环 | 呼吸不移动脚底基准 |
| run / [0,24)，0.8s | 循环 | 左右足触地标记，首尾姿态趋势连续，无根位移 |
| jump_start / [0,6)，0.2s | 非循环，混到空中 | 模拟确认起跳后播放，不等预备完成才跳 |
| jump_air / [0,12)，0.4s | 循环 | 不自行触发落地 |
| land / [0,6)，0.2s | 非循环，可打断 | 接触地/坡/顶事件触发；不因 clip 完成修改 y |
| slide_in / [0,6)，slide_loop / [0,12)，slide_out / [0,6) | 进入/退出非循环，维持循环 | 滑铲低姿态、鞋手不穿面；由模拟阶段切换 |
| lane_left / lane_right / 各[0,6) | 非循环，可叠上身倾斜 | 无根部横移；避免重复驱动换道 |
| hit / [0,9)，fail / [0,24) | 非循环，失败 hold_last | 致命结果优先；非致命反馈不得强制结束玩法 |
| hoverboard / [0,24) | 循环 | 双足挂点与板面一致；结束转回当前模拟姿态 |

交付 `.blend` 等作者源、骨架说明、统一绑定姿势、低模蒙皮、glTF/GLB、clip 清单与事件表。骨骼候选上限 48、每顶点最多4权重；根节点不缩放，脚底/背包/板/FX 挂点具名。每个 clip 明列循环、末帧策略、可打断条件、混合建议及脚步/FX 的时间标记；无攻击时 `hit_frame` 标“不适用”，无美术赋予的无敌帧。事件仅触发表现，不产生拾取、伤害、落地或结算事实；准确事件名与优先级等待 PAO-9。

FX 首批仅拾币、拾道具、护盾碎裂、落地尘；候选同屏峰值 64 粒子、每效果最多1张256贴图、生命周期不超过0.6s，同一效果固定一种混合方式。碎片不盖住障碍轮廓；低动态模式停用屏震/闪光、减粒子但保留图标与文案反馈。不使用全屏闪光或频繁红白闪烁。后续必须录屏检查跑动循环、上坡足底、滑铲进出、换道中跳跃、受击打断、暂停恢复、滑板破裂与道具到期；静态 SVG 不能验证这些。

生产资产命名示例 `mdl_train_car_a_lod0_v01.glb`、`anim_runner_run_v01`；源/导出/许可证分目录保存，同一次交付版本一致。每个资产族交1套基础样板及清单规定的LOD和动作，不虚构已交份数；允许两轮集中反馈为排期建议，需求改变另重估。模型/贴图/动作缺源文件、缺许可证或导入检验失败均退回，不以概念图通过替代。
