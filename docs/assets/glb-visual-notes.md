## 1. 怎么读（给主 Agent）

1. 先读 `glb-manifest.json`：`summary` → `known_issues_global` → `unverified_global` → `assets[]`。
2. 只在需要判断"看起来是什么样"时再打开图片，建议上限 3 张（见 §5）。
3. 每条资产自带三档状态，禁止跨档使用：

| 状态字段取值 | 含义 | 允许的说法 |
| :--- | :--- | :--- |
| `semantics.preview-confirmed` | 有真实导入截图，语义与外观都被看到 | "预览确认是…"（仍非游戏内品质验收） |
| `semantics.preview-partial` | 只有部分角度（如仅背面） | "已确认背面/侧面，正面未验证" |
| `semantics.parsed-only` | 仅 GLB 解析：包围盒比例 + baseColor 贴图配色 | "解析显示…，未做视觉核对" |
| `unverified` | 无数据 | 只能写"待验证"，不得据文件名补全 |

颜色字段来自内嵌 `baseColor` 贴图的 96px 缩略 5 色量化，**不是**视觉判断；`bounds` 是 glTF 原始单位下节点变换后的静态包围盒，**不是米制尺寸，也不能直接当碰撞代理**。
