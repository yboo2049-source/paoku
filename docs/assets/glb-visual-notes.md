## ⚠️ 核心核验发现与接入避坑警告（主 Agent 必读）

在正式将模型接入渲染管线与场景前，必须严格遵守以下经引擎复核的事实与契约，避免重复试错：

### 1. 列车资产内容与文件名完全对调
- **`train_metro.glb`**：**实际为带黄色长坡道的工程爬坡车（Ramp Train）**。前端有平缓延伸至地面的黄色防滑斜坡，用于跑上车顶。
- **`train_ramp_or_car.glb`**：**实际为标准复古现代地铁车厢（Standard Metro Train）**。带有双车灯、挡风玻璃与平车顶，正面为致死碰撞。
- *接入要求*：代码引用时必须对调映射变量；严格遵从 PAO-11/12/13 已验收的表面支撑与碰撞契约，严禁使用整车 AABB 拦截导致爬坡失败。

### 2. 622e7da 新交付的 21 个 GLB 均为静态网格（Skins: 0, Animations: 0）
- 所有 21 个新模型（包含主角、警官、警犬）**均无骨骼蒙皮与骨骼动画**。带骨骼动画的仅有历史基线资产 `player.glb`（含 67 关节、7 个动画，但缺失 jump/slide/stumble，科幻风格不搭）。
- *接入要求*：**严禁使用代码整体程序摆动替代 PAO-15 正式跑跳滑动作交付**；非刚体角色的正式动作管线待后续统一规划。

### 3. 撤回 5 个 FBX 导出模型“必须再转 X+90°”的错误结论
- `obstacle_slide_barrier.glb`、`obstacle_utility_box.glb`、`prop_jetpack.glb`、`prop_mystery_box.glb`、`prop_sneakers.glb` 共 5 个模型，其节点（Node）在 GLB 内已包含四元数旋转 `[0.7071068, 0, 0, 0.7071068]`（即 X 轴约 +90°）。
- 其局部 POSITION 访问器极值虽沿负 Z 轴分布，但经活跃场景节点变换合成后，在场景空间已是正常竖直朝向（高度 Y 轴非负，minY=0）。
- *接入要求*：Babylon.js 正常加载场景层级即可，**严禁人为在父节点二次叠加 X+90° 旋转**（否则会导致翻转 180° 再次躺平）；几何长轴本身不代表物体正面朝向，面向需按游戏摄像机视界标定。

### 4. 修正 runner 尺寸与原点推断
- `character_runner.glb` 由躯干、四肢、头部等多个部件节点平移合成。场景节点合成后的静态尺寸为 `(0.6110, 0.9791, 0.1891)`，脚底已贴近 `Y = 0`。
- *接入要求*：撤回原清单“高0.42、放大4.28倍、原点在身躯中心需下移”的建议。若按游戏标准身高 1.8m 算术归一，候选缩放约为 `1.8 / 0.9791 ≈ 1.84`（仅作为完整静态高度归一算术候选，正式导入仍需检验脚底、根变换和面向）。

### 5. 纯逻辑碰撞契约守护与非授权玩法隔离
- 信号灯、门框等环境模型作为纯视觉装饰，**严禁擅自增加物理阻挡碰撞**，必须遵守 PAO-11/12/13 已验收的纯逻辑支撑/碰撞契约。
- 新增的 `prop_jetpack`、`prop_shield`、`prop_mystery_box`、`prop_sneakers` 等模型**仍不是 PAO-14 授权玩法**，仅作为静态资产归档备用，严禁擅自推导或增加未授权的游戏机制。

## 🛠️ 后续接入标准包装模式建议（供渲染子代理使用）

在后续渲染管线接入时，建议采用以下标准容器模式管理 GLB 实例：

```typescript
// 标准 GLB 资产包装容器工厂模式建议
function instantiateProp(glbMesh: AbstractMesh, scale: number, rotY: number): TransformNode {
  const root = new TransformNode("prop_root", scene);
  glbMesh.parent = root;
  glbMesh.scaling.setAll(scale);
  // 注意：FBX 模型在 GLB 内部已完成四元数旋转，切勿在此处二次叠加 X+90°
  glbMesh.rotation.y = rotY;
  return root;
}
```

- **统一单根原则**：所有模型一律挂载在独立的 `TransformNode` 根下，对外暴露纯净的坐标系。
- **碰撞体解耦原则**：逻辑层 `physics.ts` 保持纯数学米制 Box/Ray 检测与既有契约，渲染层 GLB 仅作为视觉展示跟随物理刚体节点更新，切勿直接读取未标定的 GLB 顶点网格做碰撞！
