## Reproduce

From the repository root, run `npm run dev` and `npx playwright test -c tests/e2e/pao6.config.ts`. The dedicated config can also start Vite. Windows launch uses ANGLE D3D11. Tests temporarily replace the existing spawner in browser memory and enable existing QA setters to arrange fixtures. No game implementation is edited. Natural run uses the random production generator, so its exact route and score are not deterministic; follow the report's UI steps.

Finite CSS transitions are fast-forwarded for fixture stills using Playwright screenshot `animations: disabled`; Babylon simulation stays active. Videos retain dynamic behavior. Fixture setters and injected geometry are disclosed, and successful fixture paths do not prove random route safety.
